An entry for make.fun's [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) bounty: a monologue of about 100 words spoken by a fantasy villain who is secretly just very tired — the tiredness lives in the rhythm, the pauses and the small deflections, never in a plain statement of weariness.

`main.py` (Python 3, stdlib only) writes the monologue to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
